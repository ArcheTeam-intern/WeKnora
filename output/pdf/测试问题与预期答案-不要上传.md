# 青岚计划 PDF：测试步骤与标准答案

只上传同目录的 **WeKnora-PDF验收样本-青岚计划.pdf**。这份说明不要上传，否则会把答案当成检索资料，削弱测试价值。PDF共4页：文字资料、版本及数据表、只有图像的交接单、8个问题。

## 先确认选项的真实含义

- 当前工作台的“标准 MCP / 文件流”是上传通道，**不是解析引擎**。
- 当前“ask / LangChain Agent”是执行链，**不是 WeKnora 原生快速问答/智能推理模式**。
- 当前顶栏知识库范围与材料页目标库独立，必须手工确认二者一致。
- 在解析选择功能完成前，只能测试知识库默认解析能力；不能声称已验证“切换解析器”。

## 操作顺序

1. 选择测试知识库A，只把PDF上传到A。当前页面需同时确认顶栏范围与“目标知识库”均为A。
2. 上传后导入，等解析和索引完成。保存返回的document_id和解析状态。
3. 新建问答会话，限制到A，逐个复制下面问题。每题要求引用本次文档的原文/块，不能只看答案是否碰巧相同。
4. 切到没有本PDF的知识库B，再点“新会话”，重复Q1并要求仅依据当前知识库。应说明找不到相关资料，不得复述A的识别标记。
5. 切回A，再点“新会话”，同题应恢复有据回答。这比观察顶栏跨页面是否可见更能证明范围生效。
6. 在每个可用问答执行链分别测试。未来加入原生问答模式后，使用相同资料和问题对照。
7. Q7用于OCR/图像理解；若解析模式明确不支持图像，应报告不支持或证据不足，不能猜答案。即使模型从图像回答正确，也应检查其实际解析来源，不能仅据此断言文字索引已包含图片字段。

为免问题表本身让模型猜中，先问Q1的随机识别标记，再核验其真实引用。Q7答案只能从图像获取，当前测试PDF没有给图像添加隐藏文字层或含答案的替代文本。

## 结果如何判定

- 文字解析：Q1-6全部准确，引用本次文档且可回读；Q8明确资料不足。
- 表格/规则：Q3、Q4计算和新旧规则均正确，不能只判总结果。
- OCR/图像：Q7字段全部准确且有真实图像来源；未启用OCR时如实说明限制。
- 知识库范围：A可答、B新会话不能凭A资料作答、回A可恢复。B不应出现A的引用。
- 模式生效：记录页面选择、实际MCP参数及服务器生效模式；只见按钮变色不能算通过。
- 解析方式生效：记录实际提交的process_config及服务端解析引擎。不要用同PDF的去重结果证明另一解析引擎已重新处理；需走正式重新解析能力或隔离的唯一测试文档。

本样本只能验证这些明确场景；单文档通过不能证明多文档全量召回、跨租户授权或全部MCP工具均通过。
